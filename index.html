Quick start: set the semester, then import a timetable or add a course. The current week shows active courses; Sync sends courses to your Super Productivity plan. Export creates ICS, CSV, or JSON backups. Supported imports: CSV timetable, structured CSV, HTML tables, pasted web timetables, and XLSX. CSV timetable cells may contain course, teacher, room, and weeks; structured CSV uses one course per row; HTML preserves table, rowspan, and colspan structure. Examples: 1~3,5~16周, 4周, odd weeks, even weeks, custom weeks 1,3,5, and weekdays Monday/周一/Monday.
